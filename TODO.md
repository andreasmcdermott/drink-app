# Pour roadmap

## Next release

### Match recipe variations

- [ ] Include curated variations in drink recommendations and missing-ingredient checks.
- [ ] Explain which version can be made with the ingredients on the shelf—for example, suggest a Bourbon Manhattan when bourbon is available but rye is missing.
- [ ] Include variations in shopping recommendations without counting multiple versions of the same drink as separate unlocks.

### Save a shopping list

- [ ] Save missing ingredients from recipes and suggested purchases to a persistent shopping list.
- [ ] Combine duplicate ingredients across saved recipes.
- [ ] Show which drinks each purchase unlocks.
- [ ] Keep planned purchases separate from ingredients already on the shelf.
- [ ] Move purchased ingredients onto the shelf when marked as bought.

### Make recipes easier to use while mixing

- [ ] Display familiar ounce fractions, such as ¾ oz, while preserving accurate measurements and serving scaling.
- [ ] Add a large-text, step-by-step mixing mode.
- [ ] Keep the screen awake while mixing mode is active, restoring normal behavior when it ends.

## Following improvements

### Personalize recommendations

- [ ] Save preferred spirits, starting with gin.
- [ ] Let people rate drinks and record preferences such as tart, bitter, sweet, or spirit-forward.
- [ ] Use those preferences to rank drink recommendations and ingredient purchases.

### Save personal recipes and notes

- [ ] Create and edit personal recipes with ingredients, quantities, and instructions.
- [ ] Save tasting notes, preferred brands, and adjustments such as “use 15 ml syrup next time.”
- [ ] Include personal recipes in ingredient matching and shopping recommendations.
- [ ] Support serving scaling for personal recipes.

### Improve ingredient entry

- [ ] Suggest catalog matches for unfamiliar ingredient names.
- [ ] Ask for clarification when an entry is ambiguous—for example, “What kind of rum?”
- [ ] Preview resolved ingredients before adding them to the shelf.

## Feedback and validation

- [ ] Share a TestFlight build with a few friends after the next release improvements.
- [ ] Gather feedback while they enter their ingredients, choose a drink, and actually make it.
- [ ] Use that feedback to prioritize fixes and additions to the recipe collection.
